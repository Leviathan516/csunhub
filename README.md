# CSUN Campus Resource Hub
 https://leviathan516.github.io/csunhub/ & https://csunhub2.onrender.com/

 
A centralized web portal that helps CSUN students quickly find campus resources — maps, dining, clubs, careers, and a personalized major skill tree to track their path to graduation.
 
Built as a CIT 480 Senior Design project at California State University, Northridge.
 
## Features
 
- **Campus Map** — Interactive Google Map with toggleable layers for food, parking, and buildings, plus a search box.
- **Dining Guide** — Curated guide to on-campus eateries, housing-area spots, Sierra Center options, and nearby restaurants, with hours and directions.
- **Clubs & Organizations** — Browsable directory of student clubs grouped by category, with collapsible sections and category filters.
- **Careers** — Job, internship, and on-campus work listings tailored for CSUN students, plus an embedded CSUN Career Events calendar.
- **Student Dashboard** — Authenticated landing page linking to Canvas, the Student Center, enrollment, and degree-progress tools.
- **Major Skill Tree** — Gamified course tracker that visualizes your major's classes as a prerequisite tree. Complete a course to unlock the next tier, like leveling up a skill tree. Progress is saved per-user.
- **Authentication** — Email/password sign-up and login backed by Firebase Auth, with user profiles (username, major, catalog year) stored in Firestore.
## Tech Stack
 
- **Frontend:** HTML, CSS, vanilla JavaScript (Phantom template base)
- **Backend:** Node.js + Express (static file server with a generated config endpoint)
- **Auth & Database:** Firebase Authentication, Firestore, Realtime Database
- **Maps:** Google Maps JavaScript API
